# observ-viz

A standalone [Jsonnet](https://jsonnet.org/) library for **Grafana dashboard
schema v2** resources — slim core, lots of mixins. Its **observ-libs** each ship
signals, alert rules with runbooks, recording rules and a board. New here? Read
the [Introduction](intro.md) and its [Quickstart](intro.md#quickstart).
